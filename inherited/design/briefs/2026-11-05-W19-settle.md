# W19: every page settles without jumping

Read first, whole: `LAW.md`, `the-law-for-agents.md`, `RULINGS.md` (from 2026-11-05 16:44 on; in particular 18:28), `STATE.md`, `briefs/_COMMON.md`, research/plan/2026-11-05-A-maker-principles.md.

**Goal.** Review every page and every move between pages on the site, and fix them so that nothing jumps. The maker, 18:28 UTC 11-05, verbatim in RULINGS.md: "page transitions, sometimes information loads and then it pushes other info down, so there's a lot of snapping and glitchy moving around… I want you to be deliberate about every single page, maybe use skeleton loaders." *Reason:* his words; the site is read on phones while data arrives late.

**Work:**
1. **Inventory.** List every route and view in the app (src/, index.html, the views the router shows, sheets and drawers), and every way of moving between them.
2. **Measure.** For each route, at 390 px with touch and at 1280 px, on a slow connection (Playwright with network throttling, and the feeds delayed by routing), record:
   - cumulative layout shift, using PerformanceObserver 'layout-shift';
   - the frames as it loads.
   Note each element that moves after first paint, and why: late data, fonts, images without size, or a change in a view transition.
   Put the numbers in a table in research/ (the path your brief's common rules give), before and after.
3. **Fix.** Fix each case deliberately:
   - reserve space at the final size;
   - use skeletons that match the real shape when data is late, with no shimmer or pulse (principles 2b: no AI tells), only a still placeholder and a calm crossfade in;
   - give images and photos their size;
   - use font metrics overrides if a fallback font shifts;
   - make view transitions go between equal boxes.
   Where a skeleton would claim something untrue, such as a seat count, use an empty frame instead. *Reason:* law 7.
4. Keep:
   - the arrival cover and the door's view transition;
   - the live feeds' behaviour;
   - reduced motion;
   - tests passing; add tests where a regression is likely, such as a fixed height being missing.

**Do not touch** lib/gate/ (the door). W18 owns it. The invite card was just merged as #154; give it reserved space only if it shifts something.
