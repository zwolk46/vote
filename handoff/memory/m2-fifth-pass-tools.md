Fetch scripts (curl -sSL, 5 s apart, into `~/.cache/vote-m2/<pass>/`, index.txt with sha256; a rerun skips what is fetched): `fetch_law_pages.sh` (c27), `fetch_governor_rosters.sh` (c28), `fetch_ballot_texts.sh` (c30), `fetch_fourth_pass.sh` (c31–c33: Census files, lists, rule pages, MEDSL 2018/2020 zips by blob-less git), `fetch_fifth_pass.sh` (c34–c36: MEDSL's Dataverse files 2016 local+state (0.4+1.9 GB), 2022 and 2024 by state, 2018 zips by git, 13 NCSBE results_pct zips, NM SOS archive and PEC pages). `fetch_sixth_pass.sh` (c37: WA 2022 results/Export pages + 3 CSVs, ND archive/front/statewide/judicial pages 2022 and 2024, the 20 quote URLs of statewide-filed-local.json, MO revisor §52(b)/(a) and OK Senate PDF); MEDSL files for a new pass go into fetch_fifth_pass.sh's lists (2022 by MEDSL's own names, e.g. colorado_cleaned.csv; 2024 by state; 2018 zips by git). `m2medsl.py` summarizes each raw MEDSL/NCSBE file once into `fifth/derived/<file>.json` (counties per state-date, county precinct counts keyed per file as the pipeline keys them, state contests with counties/magnitudes/candidates, local questions with answers; 2016's answers read from wording like "Yes - X", "For", "X - AGAINST"); delete a derived file after changing m2medsl. `m2places.py` is a verbatim copy of pipeline/places.py (says so). Gotchas learned: NC's 2014 records name no class in their reason ("no earlier year to fit on") yet the pipeline pools them (primaries: "primary, <scope> <type>, <n> candidates"); MEDSL 2018 magnitudes read "1.0"; D3's moves-file code B marks p blocks whose own commit stamp moved with the note (76), Q alone where only the note changed (230). Where MEDSL files a contest's pieces under one office name (AZ 2024 CC, OR 2024 position 7) the summary merges them: read the raw rows by county (c37.raw_contests); MEDSL's AZ 2024 Santa Cruz CC rows sit under districts 001-003; the pipeline's name key joins 'BRONSON JAMES'/'BRONSON D JAMES'; a retention is a question (names 'X - YES/NO', 'TIMES BLANK VOTED' lines); a proposer_quote may carry its own url (MO §52(a)).

**Why:** a later M2 pass reuses these scripts and caches (`~/.cache/vote-m2/`) instead of refetching or rediscovering the file quirks. **How to apply:** run the fetch script of the pass first (it skips what is fetched; add new state-years to its lists), delete a `fifth/derived/` summary after changing `m2medsl.py`, and read [[m2-check-computed-p]] for the passes and open readings.
