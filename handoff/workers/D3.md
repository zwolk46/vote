## How to rebuild
1. `VOTE_CACHE=/tmp/vote-cache python3 -I pipeline/local_volume.py check`. The build reads its output.
2. Commit the code.
3. Run `bash /tmp/vote-cache/rebuild.sh`, about 3.5 minutes. It runs `intake/va_elect.py`, `local.py build --with-p`, `local_medsl.py build`, and `local_ncsbe.py check` and `build`.
4. Run `local_la.py`, `local_nj.py`, `local_nj_leg.py` and `local_va_leg.py check`.
5. Revert the files whose only change is a stamp (`commit`, `read_utc`, `computed_by`).
6. List the moves against the base, record by record (p moved, lost or gained, notes, reasons).

Never use `git commit -a`, `git stash` or `git checkout -- data/`.

## Rules that bind (from the orchestrator and the law)
- A refusal binds the whole agency: stop and report.
- A count of record needs a printed official or certified mark, or the agency's own words on the linking page. A file name is not a mark (21:55). A third party's copy never counts (21:03).
- One request every few seconds per host, with User-Agent `vote-data-research/1.0`. Never put the maker's email anywhere.
- Messages to the orchestrator are 2,000 characters at most.
